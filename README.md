# Sea Lice Risk Analysis (Scotland)

Exploratory data analysis of sea lice infestation patterns across Scottish aquaculture sites using 28,000+ records.

The project focuses on:
- Spatial distribution of lice pressure across sites
- Temporal outbreak dynamics over multiple years
- Identification of high-risk and cyclical infestation patterns

Tools:
- Python (Pandas, Matplotlib)
- Jupyter Notebooks
